# MyPace

**Your life, in your rhythm.**

A student-life planner built with Flask, HTML, CSS and vanilla JavaScript.

## Run locally

1. Create a virtual environment.
2. Install packages: `python -m pip install -r requirements.txt`
3. Start the app: `python app.py`
4. Open `http://127.0.0.1:5000`

## Current milestone

- Responsive editorial-style dashboard
- Add, complete and delete tasks
- Tasks saved in browser localStorage

Tasks are currently stored in this browser only. SQLite persistence, calendar integration and adaptive scheduling are later milestones.
